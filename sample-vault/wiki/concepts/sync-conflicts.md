# Sync conflicts

## Definition
Two copies of the same file changed independently, so the sync tool cannot merge them by itself.

## What the sources say
- Rare: about three in a year, one writer on two computers, each settled in a minute ([[local-first-software-notes]]).
- Frequent: about one a week, a team of three, usually on a shared index page; one cost an hour of edits ([[sync-conflict-field-notes]]).
- What reduced them: many small files instead of a few big pages ([[sync-conflict-field-notes]]).

⚠️ Contradiction: [[local-first-software-notes]] says sync conflicts are rare, [[sync-conflict-field-notes]] says about one a week.
The setups differ (one writer, two computers, against three writers), so both may be true. Not decided.
To check: a source that measures conflicts for the same number of writers.
