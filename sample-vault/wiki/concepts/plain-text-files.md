# Plain text files

## Definition
Storing information as readable text files (for example Markdown) instead of in a program's own database format.

## What the sources say
- A folder of Markdown files can be opened by hundreds of tools and outlives any one application ([[local-first-software-notes]]).
- Plain text makes a sync conflict readable: both versions can be seen side by side ([[sync-conflict-field-notes]]).
- Splitting big pages into many small files made conflicts less likely ([[sync-conflict-field-notes]]).
