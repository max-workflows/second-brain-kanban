# Local-first software

## Definition
Software that keeps the primary copy of the user's data on the user's own device, so it works offline and the data
survives the vendor.

## What the sources say
- The server only helps with syncing; the app keeps working without the network ([[local-first-software-notes]]).
- Waiting for a server before typing a note is treated as a design failure, not a connectivity problem ([[local-first-software-notes]]).
- Advice: store data as readable files, keep a copy you control, treat the cloud as a convenience.
