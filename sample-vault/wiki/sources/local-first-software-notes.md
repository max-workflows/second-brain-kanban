# Notes on local-first software

## Summary
An essay by [[ada-larkin]] on keeping the primary copy of data on the user's own device. It names three ideas: plain text
formats outlive applications, apps should work offline by default, and syncing should be boring. It ends with practical advice.
Invented demo text.

## Key claims
- [[local-first]]: the primary copy of the data lives on the user's device; the server only helps with syncing.
- [[plain-text-files]]: a folder of Markdown files can be opened by hundreds of tools and outlives any one application.
- Working offline is the default, not a special mode.
- Sync conflicts are rare: the author saw "perhaps three in a year" while writing alone on two computers. See [[sync-conflicts]].

⚠️ Contradiction: this source says sync conflicts are rare, while [[sync-conflict-field-notes]] reports about one a week in a team of three.
The situations differ (one writer, two computers, against three writers), so the claims may not truly clash. Not decided; see [[sync-conflicts]].

## Quotes
- "treat the cloud as a convenience, not as the owner of your notes"
